**C-Route** هو نظام بنية تحتية تشغيلية متكامل لإدارة سلاسل الإمداد، مصمم خصيصاً لربط المصانع، التجار، والسائقين في منصة تقنية واحدة تضمن السرعة، الشفافية، والتمويل الذكي.

🔗 **رابط العرض المباشر**: [croute.vercel.app](https://croute.vercel.app/)

---

## 🚀 المميزات الرئيسية (Core Features)

### 🏭 بوابة المصانع (Factory Hub)
*   **إدارة الشحنات**: رفع وتتبع الشحنات لحظة بلحظة.
*   **التحليلات الذكية**: مراقبة انتشار المنتجات في السوق عبر خريطة تفاعلية واقعية.
*   **التسويات الفورية**: تحصيل المبالغ فور استلام التاجر للبضاعة.

### 🛒 بوابة التجار (Retailer Marketplace)
*   **سوق مفتوح**: الوصول المباشر لمنتجات المصانع بأسعار تنافسية.
*   **تمويل تشغيلي**: تسهيلات ائتمانية مرنة (Pay Later) لزيادة القوة الشرائية.
*   **تتبع لوجستي**: معرفة مسار الشحنة ووقت الوصول المتوقع.

### 🚚 بوابة السائقين (Driver Dispatch)
*   **تحسين المسارات**: خوارزميات ذكية لتقليل المسافات وزيادة الأرباح.
*   **تسوية يومية**: استلام مستحقات التوصيل بشكل آلي وفوري.

---

## 🛠 التكنولوجيا المستخدمة (Tech Stack)

*   **Frontend**: React.js with Vite (Lightning fast performance).
*   **Styling**: Tailwind CSS (Custom Premium UI/UX).
*   **Backend & DB**: Supabase (Real-time data & secure Auth).
*   **Animations**: Framer Motion (Smooth high-end interactions).
*   **Icons**: Lucide React.

## 📸 نظرة على النظام (Preview)

النظام مصمم بواجهات **Premium** تدعم الـ **Light Mode** وتجربة مستخدم (UX) فائقة السلاسة على الكمبيوتر والهاتف.

*   **Role Selection**: واجهة دخول ذكية لاختيار صفة المستخدم.
*   **Analytics Dashboard**: لوحة بيانات متكاملة مع خرائط حرارية للتوزيع.
*   **Invoice System**: نظام فواتير احترافي قابل للطباعة والتحجيم التلقائي.

## 💻 التشغيل المحلي (Local Setup)

1.  قم باستنساخ المستودع:
    ```bash
    git clone https://github.com/Fadl711/Croute.git
    ```
2.  تثبيت المكتبات:
    ```bash
    pnpm install
    ```
3.  تشغيل بيئة التطوير:
    ```bash
    pnpm run dev
    ```
